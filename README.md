# AbyssalEcho

It's a fast-paced 2D top-down action game written in pure Python using Tkinter. Navigate through the stone arena, dodge the boss's precision laser, manage your stamina for ramming shields and guided plasma lasers, and survive waves of enemies to achieve victory.

## BUILT WITH
Python 3 (Tkinter, Math, Random)

### RUN LOCALLY
Download or clone this repository, open a terminal in the project folder, and run:
```
python main.py
